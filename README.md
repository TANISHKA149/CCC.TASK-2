TechSphere – Tech Blog Website

📌 About the Project

TechSphere is a simple and modern technology blog website created using HTML and CSS.

The website provides technology-related articles on topics such as Artificial Intelligence, Web Development, and Cloud Computing. It is designed with a clean layout, attractive cards, navigation, and a responsive structure.

🎯 Objective

The main objective of this project is to create a tech blog and article platform where users can:

- Explore technology-related topics
- Read the latest articles
- View trending posts
- Open individual articles
- Navigate between different sections of the website

✨ Features

- 🏠 Home Page with a hero section
- 📰 Latest Articles section
- 🔥 Trending Posts section
- 🤖 Artificial Intelligence article
- 🌐 Web Development article
- ☁️ Cloud Computing article
- 📄 Separate article page
- 🖼️ Image integration
- 🔗 Navigation links
- 🎨 Modern gradient-based UI
- 📱 Responsive layout
- ⚡ Simple and lightweight design

🛠️ Technologies Used

- HTML5 – Used to create the structure of the website
- CSS3 – Used for styling, layout, colors, cards, spacing, and responsiveness
- JPEG Image – Used for the article image

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all files are in the same folder.
4. Open "index.html".
5. Run it using a browser or Live Server.
6. Click the navigation links to explore the website.
